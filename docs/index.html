Safe by default

Copies files instead of moving them, avoids symbolic links, and preserves name collisions with numbered suffixes.

02
Runs anywhere

Built on the Python standard library for Windows, Linux, and Termux — with no runtime dependencies.

03
Auditable results

Every completed run produces a clear JSON report with counts, copied paths, skips, and errors.
